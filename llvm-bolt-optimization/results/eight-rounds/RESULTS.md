## 结果解释

关联负载的 1.70% 是两组中位数的观测差，不能直接认定为稳定加速。
按重复轮次配对的改善中位数约 1.15%，探索性 bootstrap 95% 百分位区间为 -1.98% 至 +3.00%，跨越零；计算方法和全部结果见 `uncertainty.json` 及 `scripts/analyze_uncertainty.py`。
bootstrap 假设重复轮次相互独立，不能消除 WSL 调度与 CPU 频率影响。

普通程序和关联负载的 CDSort 基线均为零交换，观测时间差不能归因于新布局。
分散调用的距离改善很小（exec-count 基线上约 0.00061%），没有可靠的时间收益证据。
因此，本次确认的是布局指标改善和功能正确性；稳定性能提升仍未得到证明。

所有开启/关闭对照的 CODE 段总大小一致，没有代码体积缩减。
文件大小相较原始程序增大，需计入 BOLT 保留原始代码、重写代码、重定位及 hot-text 对齐的共同开销。
